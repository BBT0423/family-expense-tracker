# SummaryYearSalary Web

Vue.js 3 frontend application for SummaryYearSalary.

## Project Setup

```sh
npm install
```

### Development Server

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Lint with ESLint

```sh
npm run lint
```

## Configuration

- API endpoint: Edit `VITE_API_BASE_URL` in `.env` file
- Proxy configuration: Edit `vite.config.ts`

## Tech Stack

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia
- Axios
